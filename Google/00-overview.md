# Google Frontend Engineer Interview — Overview

## Interview Loop Structure (L5 / Senior)

| Round | Duration | Focus |
|-------|----------|-------|
| Recruiter Screen | 30 min | Background, role fit |
| Technical Phone Screen 1 | 45-60 min | DSA (1-2 LeetCode problems in JS) |
| Technical Phone Screen 2 | 45-60 min | DSA / Frontend fundamentals |
| Onsite — Coding 1 | 45 min | DSA — medium/hard |
| Onsite — Coding 2 | 45 min | DSA — medium/hard |
| Onsite — Frontend | 45 min | JS coding, DOM, CSS, React concepts |
| Onsite — System Design | 45 min | Frontend system design (component + architecture) |
| Onsite — Behavioral (G&L) | 45 min | Googleyness & Leadership |

> Google FE interviews are **DSA-heavy**. Expect at least 2-3 pure algorithmic rounds in JS.

---

## What Google Is Looking For

### Technical Leadership
- Lead design decisions, make architecture trade-offs
- Mentor and influence beyond your own code

### Problem Solving & Ambiguity
- Ask clarifying questions before coding
- Define scope, handle edge cases, drive to a clean solution

### End-to-End Ownership
- Can you design AND build AND launch a full feature?

### Communication
- Think out loud; explain trade-offs continuously
- Walk through time/space complexity without being prompted

---

## Language & Tools
- You may use **JavaScript** (preferred for frontend roles)
- Know ES6+ thoroughly: Promises, async/await, destructuring, generators, Proxy
- No external libraries in coding rounds unless explicitly allowed

---

## Scoring Dimensions (Hire Bar)
1. General Cognitive Ability
2. Leadership
3. Googleyness (collaboration, comfort with ambiguity)
4. Role-Related Knowledge
