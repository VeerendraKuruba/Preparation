## Typical Interview Process (5–6 Rounds)

| Round | Format | Duration | Focus |
|-------|--------|----------|-------|
| 0 | Recruiter Screen | 30 min | Experience, compensation, timeline |
| 1 | Technical Coding | 60–90 min | DSA (Medium LeetCode) + JS fundamentals |
| 2 | Technical Deep-Dive | 60–90 min | React internals, architecture, performance |
| 3 | Frontend System Design | 60–90 min | HLD for large-scale UI, micro-frontends, API design |
| 4 | Principal/Leadership Round | 60 min | Mentorship, cross-team influence, technical strategy |

## Principal vs Senior — Key Differentiators

| Aspect | Senior | Principal |
|--------|--------|-----------|
| Scope | Team/feature level | Org/product level |
| Design | Implements architecture | **Defines** architecture across teams |
| Influence | Within own team | Cross-team, cross-functional |
| DSA | Core competency | Filter (still tested) |
| System Design | Can design a feature | Can design an entire platform |
| Mentorship | Occasional | Systematic (raises bar of entire team) |
