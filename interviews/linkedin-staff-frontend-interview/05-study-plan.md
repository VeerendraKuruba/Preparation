## Readiness Checklist (Day Before)

### Soft skills (15 min block)
- [ ] 3 pillars defined in your own words (Kevin Scott)
- [ ] 7 craftsmanship pillars — name at least 5 (Alex Vauthey)
- [ ] Story: team led in your absence
- [ ] Story: upleveled another engineer
- [ ] Story: conflict mitigation
- [ ] 2-min intro + why LinkedIn

### Technical (45 min block)
- [ ] UI module from mockup in ≤ 20 min (HTML+CSS)
- [ ] Memoize from memory in ≤ 8 min
- [ ] Explain: events, prototype inheritance, async/await
- [ ] Functional state pattern — reducer + immutable updates
- [ ] 1 LC easy in ≤ 15 min with 3 edge cases stated upfront
- [ ] Testing strategy ready: "I'd unit test reducer; integration test DOM; a11y audit"
- [ ] CoderPad / browser tested
- [ ] Reviewed https://imgur.com/4YXYSsu
