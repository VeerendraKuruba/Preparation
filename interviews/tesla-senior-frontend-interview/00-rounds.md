## Day-of Strategy

### Before onsite
- 10 min warmup: longest substring + sketch car rental boxes
- STAR bullet sheet printed

### During coding (R4–R6)
- Clarify → approach → code → trace example
- UI rounds: component list in comments first

### During system design (R7)
- User journeys before infrastructure names
- Propose API endpoints out loud

### Red flags
- UI-only answers with no data/API plan
- No loading/error states in UI build
- Blaming teams in behavioral
