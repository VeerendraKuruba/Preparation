# SurveyMonkey — Senior Software Engineer II (Frontend) Interview Prep

## Interview Structure (3 Rounds)

| Round | Format | Duration | Focus |
|-------|--------|----------|-------|
| Round 1 | Live Coding | ~90 min | JavaScript fundamentals + React + Build a feature from scratch |
| Round 2 | Virtual Whiteboard | ~60 min | System Design + Low Level Design (LLD) |
| Round 3 | Techno-Managerial | ~45 min | Behavioral + Technical depth + Leadership |

## Key Tips from Real Candidates (Glassdoor/Hashnode)

- **CSS matters** — even if the interviewer says it doesn't, weak CSS will count against you
- **Round 2 System Design**: Ask clarifying questions upfront before diving in — problems are often under-communicated
- **Round 3**: Treat it like a normal conversation; be yourself, show ownership and impact
- **API Integration**: Expect to build a real UI component that fetches data from a mock API
- **No need to implement fully** in system design — understanding the problem and proposing a feasible solution is key
