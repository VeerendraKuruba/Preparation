Demo 3 — What creates a stacking context?

Root element <html>

The page itself is always a stacking context.

position + z-index position: relative;
z-index: 1;

Any non-auto z-index on a positioned element.

opacity opacity: 0.99;

Any value less than 1 triggers a new context.

transform transform: translateX(0);

Even a no-op transform creates a context.

filter filter: blur(0);

Same as transform — context is created.

will-change will-change: transform;

Hints to browser → creates context early.

isolation isolation: isolate;

Explicitly creates a context. Most predictable.

mix-blend-mode mix-blend-mode: multiply;

Blending requires its own context.
